##  Contenido del Repositorio

### 1.  Proyecto Final: Marketing Bancario
Ubicación: [`/proyecto_aula`](./proyecto_aula)

Análisis completo del ciclo de vida de datos para una campaña de marketing bancario. El proyecto se divide en las siguientes etapas y archivos:

* **Notebooks de Análisis:**
    * `Analisis_Marketing_Bancario.ipynb`: Análisis Exploratorio de Datos (EDA), limpieza inicial y visualización de patrones.
    * `Preprocesamiento_Datos_Bancarios.ipynb`: Ingeniería de características (codificación, escalamiento y transformación) para preparar los datos para modelos de IA.

* **Datos (`/data`):**
    * `bank.csv`: Dataset original.
    * `bank_depurado.csv`: Dataset limpio (sin valores 'unknown').
    * `bank_preprocesado.csv`: Dataset final (escalado y codificado) listo para modelado.

* **Manuscrito Científico:**
    * Ubicación: [`/articulo`](./articulo)
    * Archivo: **`FCD_Articulo_Final_Alejandro_Orrego_Roldan.pdf`**
    * Contiene el informe final en formato PDF con la introducción, metodología, resultados y conclusiones del estudio.
